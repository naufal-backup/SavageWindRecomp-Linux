**Alpha 2 for Linux.** The same build as upstream's Alpha 2: *The Legend of Zelda: Breath of the
Wild* 1.8.2 through the opening in the Shrine of Resurrection and out onto the Great Plateau at
60 fps, with sound, voices, the HUD, saving and loading. Nobody has played past the Great Plateau
yet: expect bugs or crashes further on, and please report what you find.

> [!IMPORTANT]
> **No game files are included.** You need your own legally obtained copy of the game, updated to
> **version 1.8.2**, extracted from **your own** Nintendo Switch. Savage Wind provides no game
> files, keys, firmware, dumping or decryption tools, or instructions to obtain any of them, and
> it never decrypts anything. The game code is recompiled on your machine, from your files, for
> your own use only: don't share it. This is a fan project, not affiliated with or endorsed by
> Nintendo.

## Download

`Savage_Wind-0.2.0-alpha.2-x86_64.AppImage` (verify it against `SHA256SUMS`).

## Running it

    chmod +x Savage_Wind-0.2.0-alpha.2-x86_64.AppImage
    ./Savage_Wind-0.2.0-alpha.2-x86_64.AppImage

The start screen asks for the folder with your own game files (`exefs/` and `romfs/`, version
1.8.2) and sets them up: it builds the data image and recompiles the game code on your machine,
once. From then on it goes straight into the game. `--config`, or the **Savage Wind Configuration**
desktop action, opens the configuration screen.

Everything the app writes lives in `~/.local/share/savagewind`; `SAVAGEWIND_DATA_ROOT=<dir>` uses
another folder.

## Built on Arch Linux

This AppImage is built in an Arch Linux container with the distribution's own toolchain
(clang 23, the Arch version of the SDL3 / FFmpeg / shaderc headers' consumers), so:

- It needs a **recent distribution**: Arch, CachyOS, Fedora rawhide, and future releases. Measured
  on this build, the binary requires **GLIBC_2.43**; it does not run on Ubuntu 24.04 or Debian 13.
- SDL3, an LGPL-only FFmpeg, shaderc and the start screen font are bundled. Not bundled: glibc,
  libstdc++, the Vulkan loader and the GPU drivers, which are always the system's.
- A GPU with Vulkan 1.3 is needed, and an x86-64 CPU with AVX2.

For a build that runs on older distributions (glibc 2.35+), build it yourself with `make appimage`
(ubuntu image) as `docs/linux.md` describes.

## Known issues

- Only the Shrine of Resurrection and the Great Plateau have been played.
- DLC isn't supported. Only game version 1.8.2 is accepted.
- Reports of stuttering, distant LOD problems and other graphics issues are tracked upstream in
  [Revivedx/SavageWindRecomp issues](https://github.com/Revivedx/SavageWindRecomp/issues).
